# 宝可梦传说 阿尔宙斯 · 洗翠攻略（单文件离线 PWA）

一个 **单文件、纯本地、离线可用** 的《宝可梦传说 阿尔宙斯》洗翠地区攻略工具。全部图鉴 / 属性克制 / 捕捉地点数据内嵌在 `index.html` 里，不依赖任何服务器、CDN 或框架——拷贝这一个文件就能用，也支持 iPad 通过局域网访问并"添加到主屏幕"当 App 用。

> 本项目是个人游戏攻略工具，与任天堂 / The Pokémon Company 无关，数据仅用于学习与个人使用，请勿商用。

## 🚀 快速开始

### 电脑本地（推荐）

双击根目录的 **`启动攻略.bat`**，会自动：

1. 检查 Python（未安装会提示去装）
2. 若 8000 端口已在运行 → 直接打开浏览器
3. 否则启动本地服务器（独立窗口，标题「攻略服务器」）并自动打开浏览器

浏览器访问：`http://localhost:8000/index.html`

也可以手动跑：

```bash
python -m http.server 8000 --directory ./
```

### 直接打开单文件

不启动服务器也能用：直接双击 `index.html`（`file://` 协议下数据、收藏、克制计算全部可用；仅部分浏览器的 localStorage 在 file 协议下有限制，优先用上面服务器方式）。

### iPad 使用（局域网，推荐）

1. 电脑和 iPad 连**同一个 WiFi**，电脑上双击 `启动攻略.bat`
2. 窗口里会显示局域网地址（形如 `http://192.168.x.x:8000/index.html`）
3. iPad 用 **Safari** 打开这个地址
4. 点分享按钮 → **「添加到主屏幕」** → 之后像 App 一样全屏使用

> 注意：若 iPad 打不开，多半是 Windows 防火墙拦了 8000 端口——在「允许应用通过 Windows 防火墙」里给 Python 勾上"专用"即可。

### 微信传输到 iPad（备用）

微信传输单个 `index.html` 后，iOS 微信内可能没有"Safari 打开"选项，因此**首选上面局域网方式**；若必须传输单文件，可用隔空投送 / iCloud Drive / 邮箱发给自己，再从「文件」App 里用 Safari 打开。

## 🔧 数据与技术说明

- **数据来源**：神奇宝贝百科（wiki.52poke.com）——属性、种族值、进化链、捕捉地点（洗翠全图鉴 242 只）；PokeAPI 补全结构化字段与官方小尺寸 sprite（仅个人本地使用）。
- **图片**：PokeAPI 官方 sprite，小尺寸在线懒加载；六尾（洗翠）/ 九尾（洗翠）2 只官方未收录，使用名字占位。
- **技术栈**：纯原生 HTML / CSS / JS，零依赖、零构建工具、零外部库（无 CDN / 无框架 / 无 Service Worker 依赖）。目标兼容 iOS 15+ Safari：hash 视图切换、flex/grid、localStorage、IntersectionObserver、BigInt。
- **单文件体积**：约 300 KB（含 245 条图鉴与 3778 条地点记录），首屏即用。
- **数据可复现**：`python scripts/build_app.py` 从 `index.template.html` 重新生成 `index.html`。
- **属性克制矩阵**：18×18 权威表（2x / 0.5x / 0 / 1x）整体校验（`type_chart_audit.py` 逐格比对 0 差异，修正过 19 处抓取/清洗错误）。

### 完克配队算法口径

- **完克五队**：单属性对手需攻击完克 + 防御完克（18 种全覆盖，无豁免）；双属性对手需攻击或防御完克（153 种全覆盖）。最小规模 **4 只**共 2 种组合；5 只方案 3461 种。
- **完克六队**：防御向口径，任何单/双属性对手至少一只不被克（≤1x）；严格 ≤0.5x 抗住的对手越多越优，补位按严格抗住数排序。经枚举验证，6 只存在 33 万+ 组可行解。
- **最终进化占坑规则**：仅当进化是"纯追加属性"（如水水獭 水→水+恶）才按最终形态计算；若进化会替换/丢失属性或存在多条不同属性分支（如飞天螳螂→巨钳螳螂 / 劈斧螳螂），按当前形态属性计算，不替用户猜分支。
